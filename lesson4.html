HTTP STATUS CODES

Understand how web servers respond to your requests.

1. HTTP 200 – OK

Server ne request successfully receive aur process ki.

200 OK

2. HTTP 301 – Redirect

Website ya page kisi doosre URL par permanently move ho gaya hai.

301 Moved Permanently

3. HTTP 403 – Forbidden

Server ne request samajh li, lekin access ki permission nahi di.

403 Forbidden

4. HTTP 404 – Not Found

Requested page ya resource server par nahi mila.

404 Not Found

5. HTTP 500 – Internal Server Error

Server ke andar unexpected error aa gaya.

500 Internal Server Error

🧪 PRACTICAL CURL PRACTICE

Apne Android terminal mein ye commands practice karein:

curl -I https://example.com

curl -I -L https://example.com

curl -s -o /dev/null -w "%{http_code}\n" https://example.com

Ye commands website ka HTTP response status check karti hain.

🎯 HOMEWORK

In paanch status codes ke naam aur meanings yaad karein:

200, 301, 403, 404, 500

Practice sirf apni ya authorized websites par karein.
