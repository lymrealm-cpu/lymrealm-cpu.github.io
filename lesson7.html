🛡️ LESSON 07

DNS BASICS

Learn how domain names are translated into IP addresses.

1. What is DNS?

DNS ka full form Domain Name System hai. Ye domain name ko IP address mein translate karne mein madad karta hai.

example.com → IP Address

2. What is Domain Name?

Domain website ka readable naam hota hai, jaise:

google.com example.com

3. What is IP Address?

IP address network par device ya server ki pehchan hota hai.

IPv4 Example: 192.0.2.1

4. DNS Lookup

DNS lookup se domain ke DNS records ki information milti hai.

nslookup example.com

5. CURL Practice

Apne Android terminal mein practice karein:

curl -I https://example.com

DNS records dekhne ke liye:

nslookup example.com

Agar nslookup available nahi hai, to Android par Termux mein package install karna par sakta hai.

6. DNS Record Types

A: IPv4 address

AAAA: IPv6 address

CNAME: Another domain name ka alias

MX: Mail server information

TXT: Text information
