Lesson 02: Linux Basics

What is Linux?

Linux is an operating system used in computers, servers and cybersecurity environments.

Basic Linux Commands

pwd — Shows your current directory.

ls — Lists files and folders.

cd — Changes directory.

mkdir practice — Creates a folder named practice.

clear — Clears the terminal screen.

Practice Exercise

Learn what each command does. Practice only in your own device or an authorized lab.
