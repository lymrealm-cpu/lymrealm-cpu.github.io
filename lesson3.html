Lesson 03: Learning CURL Commands

What is CURL?

cURL is a command-line tool used to transfer data between a device and a server using URLs.

Basic CURL Commands

curl --version

Checks the installed cURL version.

curl https://example.com

Requests a webpage and displays its response.

curl -I https://example.com

Displays the HTTP response headers.

curl -L https://example.com

Follows HTTP redirects.

Practice Exercise

Try these commands on example.com, a public test website. Observe the server responses.

Only test websites and systems you own or have permission to test.
