Lesson 08 - DNS Records & Subdomains

White Hat Ethical Hacking Academy

1. What is DNS?

DNS stands for Domain Name System. It translates domain names into IP addresses so computers can find websites.

Example: example.com is a domain name that DNS can resolve to an IP address.

2. Types of DNS Records

A Record: Maps a domain name to an IPv4 address.

AAAA Record: Maps a domain name to an IPv6 address.

CNAME Record: Makes one domain name an alias of another.

MX Record: Identifies mail servers for a domain.

TXT Record: Stores text information, often used for domain verification and email security.

NS Record: Identifies the authoritative name servers for a domain.

3. DNS Lookup with Termux

Run these commands in Termux:

Find the IP address:

nslookup example.com

Find MX records:

nslookup -type=MX gmail.com

Find NS records:

nslookup -type=NS example.com

Find TXT records:

nslookup -type=TXT example.com

4. What is a Subdomain?

A subdomain is an additional part of a main domain name.

Examples:

www.example.com
mail.example.com
blog.example.com
shop.example.com

Each subdomain can be configured for a different service or purpose.

5. Practical Exercise

Run the following commands and observe the results:

nslookup example.com
nslookup -type=MX gmail.com
nslookup -type=NS example.com

Write down the IP address and the DNS records you discover.

6. Security and Ethical Rules

DNS information can help security professionals understand how a domain is configured.

Only investigate domains you own or have permission to test. Never use DNS information to attack systems.
