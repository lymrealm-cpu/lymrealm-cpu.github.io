👑 Lesson 08 - DNS Records & Subdomains

White Hat Ethical Hacking Academy

1. DNS کیا ہے؟

DNS کا مطلب Domain Name System ہے۔ یہ ویب سائٹ کے نام کو IP Address میں تبدیل کرتا ہے۔

مثال: example.com کا IP Address معلوم کرنے کے لیے DNS استعمال ہوتا ہے۔

2. DNS Records کی اقسام

A Record: Domain کو IPv4 Address سے جوڑتا ہے۔

AAAA Record: Domain کو IPv6 Address سے جوڑتا ہے۔

CNAME: ایک Domain کو دوسرے Domain کا Alias بناتا ہے۔

MX: Email Server کی معلومات دیتا ہے۔

TXT: Domain کی اضافی معلومات، مثلاً SPF، محفوظ کرتا ہے۔

NS: Domain کے Name Servers بتاتا ہے۔

3. Android پر DNS Practice

Termux کھولیں اور یہ Command چلائیں:

nslookup example.com

MX Record چیک کریں:

nslookup -type=MX gmail.com

NS Record چیک کریں:

nslookup -type=NS example.com

4. Subdomain کیا ہے؟

Subdomain کسی Domain کا ذیلی حصہ ہوتا ہے۔

مثالیں:

www.example.com
mail.example.com
blog.example.com

5. آج کی Practice

یہ Commands چلائیں:

nslookup example.com
nslookup -type=MX gmail.com
nslookup -type=NS example.com

ہر Command کا Result سمجھنے کی کوشش کریں۔

6. Ethical Hacking Rule

DNS کی معلومات صرف اپنی ویب سائٹ یا ایسی ویب سائٹ پر چیک کریں جس کی اجازت آپ کے پاس ہو۔
