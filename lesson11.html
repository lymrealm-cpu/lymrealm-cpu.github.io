LESSON 11

IP ADDRESS & MAC ADDRESS

01 - What is an IP Address?

An IP Address is a unique network address used to identify a device on a network.

It helps devices communicate with each other.

Example IPv4: 192.168.1.10

02 - What is IPv4?

IPv4 is a common IP address format. It contains four numbers separated by dots.

Example: 192.168.0.1

03 - What is IPv6?

IPv6 is a newer IP address format created to provide many more network addresses.

Example: 2001:db8::1

04 - What is a MAC Address?

A MAC Address is a hardware address assigned to a network interface.

Example: 00:1A:2B:3C:4D:5E

05 - IP Address vs MAC Address

  • IP Address identifies a device's network location.
  • MAC Address identifies a network interface on a local network.
  • IP addresses can change when a device joins another network.
  • MAC addresses are usually assigned to network interfaces.

06 - Important Security Rules

  • Never share private network details publicly.
  • Only inspect devices and networks you own or have permission to test.
  • Do not try to access another person's device without permission.

07 - Practical Training

On Android, open Wi-Fi settings and check the details of your connected network.

You may find your device's IP address there.

On a computer, you can use these commands:

ipconfig (Windows)

ip addr (Linux)

These commands display network interface information.

08 - Knowledge Test

Q1: Which address identifies a device's network location?

Answer: IP Address

Q2: What does MAC stand for?

Answer: Media Access Control

Q3: Which is the newer IP format?

Answer: IPv6
