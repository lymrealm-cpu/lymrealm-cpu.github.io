🛡️ LESSON 06

HTTP METHODS

Learn how HTTP methods control communication between clients and servers.

1. GET

GET server se information hasil karne ke liye use hota hai.

curl -X GET https://example.com

2. POST

POST server ko data bhejne ke liye use hota hai.

curl -X POST https://httpbin.org/post \ -H "Content-Type: application/json" \ -d '{"name":"LYM REALM"}'

3. PUT

PUT kisi resource ko create ya replace karne ke liye use hota hai.

curl -X PUT https://httpbin.org/put \ -H "Content-Type: application/json" \ -d '{"name":"LYM REALM"}'

4. PATCH

PATCH resource ke kisi hissa ko update karta hai.

curl -X PATCH https://httpbin.org/patch \ -H "Content-Type: application/json" \ -d '{"name":"LYM"}'

5. DELETE

DELETE kisi resource ko delete karne ki request bhejta hai.

curl -X DELETE https://httpbin.org/delete
