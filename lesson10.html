LESSON 10

NETWORK PORTS & SERVICES

TOPIC 01

What is a Network Port?

A network port is a communication endpoint used by computers to communicate with different network services.

Ports help a computer identify which service should receive network traffic.

TOPIC 02

Common Network Ports

Port Service
21FTP
22SSH
53DNS
80HTTP
443HTTPS
TOPIC 03

HTTP vs HTTPS

HTTP commonly uses port 80.

HTTPS commonly uses port 443 and protects communication with encryption.

TOPIC 04

Understanding SSH

SSH stands for Secure Shell. It is commonly used for secure remote access to computers and servers.

Default Port: 22

TOPIC 05

CURL Practical Training

Open Termux and run:

curl -v https://example.com

Look for the connection details. HTTPS normally connects using port 443.

TOPIC 06

Important Security Rules
