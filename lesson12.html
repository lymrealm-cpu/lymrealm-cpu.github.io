LESSON 12

DNS ENUMERATION & SUBDOMAIN DISCOVERY

01 - What is DNS?

DNS stands for Domain Name System.

DNS translates domain names into IP addresses so computers can find websites.

Example: example.com

02 - What is DNS Enumeration?

DNS Enumeration means collecting publicly available DNS information about a domain.

Security professionals use it to understand and protect their own domains.

03 - What is a Subdomain?

A subdomain is an additional part of a main domain name.

Example:

Main domain: example.com

Subdomain: blog.example.com

Another example: mail.example.com

04 - Common DNS Records

  • A: Connects a domain to an IPv4 address.
  • AAAA: Connects a domain to an IPv6 address.
  • MX: Identifies mail servers.
  • NS: Identifies authoritative name servers.
  • CNAME: Points one domain name to another.
  • TXT: Stores text information, often used for verification.

05 - Why DNS Security Matters

  • Helps identify incorrect DNS settings.
  • Helps protect websites and email services.
  • Helps security teams understand their domain infrastructure.
  • Can reveal publicly exposed services that need protection.

06 - Practical DNS Training

We will use a public example domain for learning.

Command 1: Check DNS information

nslookup example.com

Command 2: Check a mail server record

nslookup -type=MX example.com

Command 3: Check name servers

nslookup -type=NS example.com

These commands help you understand DNS responses.

07 - Subdomain Discovery

Subdomains are used for different services of a website.

Examples:

  • www.example.com
  • blog.example.com
  • mail.example.com
  • shop.example.com

Only investigate domains you own or have permission to test.

08 - Important Security Rules

  • Use DNS tools only for authorized learning.
  • Do not access private systems without permission.
  • Never attempt to exploit discovered subdomains.
  • Report security problems responsibly.
