Lesson 09 - WHOIS & Domain Information

White Hat Ethical Hacking Academy

1. What is WHOIS?

WHOIS is a lookup service used to find registration information about domain names.

It may show the registrar, registration dates, expiry dates and name servers.

Some personal details may be hidden by domain privacy services.

2. Important WHOIS Information

Domain Name: The registered website name.

Registrar: The company where the domain was registered.

Creation Date: The date the domain was registered.

Expiry Date: The domain registration expiry date.

Name Servers: Servers responsible for DNS information.

Domain Status: The current registration status of a domain.

3. Install WHOIS in Termux

Update Termux packages:

pkg update

Install WHOIS:

pkg install whois

View WHOIS help:

whois --help

4. WHOIS Lookup Practice

Run a lookup for a public example domain:

whois example.com

Look for these fields in the result:

  • Registrar
  • Creation Date
  • Expiry Date
  • Name Server
  • Domain Status

5. Domain Privacy

Domain privacy services help protect personal registration details from public display.

Not every WHOIS lookup reveals the domain owner's personal information.

6. Practical Exercise

Use WHOIS to inspect example.com.

Write down the registrar, creation date, expiry date and name servers if available.

Compare the WHOIS information with the DNS information learned in Lesson 08.

7. Ethical Rules

Use public domain information responsibly.

Do not use registration details to harass, target or expose people.

Only perform security testing on systems you own or have permission to test.
