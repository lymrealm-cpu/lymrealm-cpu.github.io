HTTP REQUEST & RESPONSE HEADERS

Learn how browsers and web servers communicate.

1. What is HTTP Request?

Jab browser server se webpage ya data mangta hai, usay HTTP Request kehte hain.

Browser → Server GET / HTTP/1.1

2. What is HTTP Response?

Server jab browser ko jawab deta hai, usay HTTP Response kehte hain.

Server → Browser HTTP/1.1 200 OK

3. Request Headers

Request Headers server ko request ke bare mein information dete hain.

Host: example.com User-Agent: Mozilla/5.0 Accept: text/html

4. Response Headers

Response Headers server ke jawab ke bare mein information dete hain.

Content-Type: text/html Content-Length: 1256 Server: Example

5. CURL Practical

Apne Android terminal mein ye commands practice karein:

curl -I https://example.com curl -v https://example.com curl -H "User-Agent: LYM-REALM" https://example.com

-I response headers dikhata hai.

-v request aur response ki detailed information dikhata hai.

-H custom request header bhejta hai.
